# Script Prompt utilizado

Eu quero criar um ERP de consultório para vender para clientes, com ele eu pretendo atender consultórios diversos, como de massoterapia, dentista, psicologia, entre outros tipos de clínicas pequenas. Ele deve ter algumas funcionalidades como:

- Painel de administração (Dashboard)
- Criação de usuários (pacientes), Usuários (Doutores)
- Agendamento e gerenciamento de consultas
- Controle financeiro (Faturamento)
- Prontuário médico e ficha de pacientes
- Receitas
- Mensagem no WhatsApp avisando o paciente da consulta marcada e pedindo para confirmar

Por enquanto é isso, mas futuramente quero fazer implementações diferentes conforme a necessidade.

Inicialmente o sistema vai ser uma plataforma web responsiva para conseguir ser utilizada por celular ou tablet também caso necessário.

## Desafios

Os principais desafios que vejo atualmente no gerenciamento de um consultório são:

- A dificuldade de administrar horário das consultas
- Perfil de pacientes, como o histórico de consultas, onde pode ficar armazenada a avaliação feita no dia, entre outras informações.
